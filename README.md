# machine learning practice

book examples, exercises, and small experiments while learning machine learning and deep learning.

## books in use

1. [deep learning with python, third edition](https://www.manning.com/books/deep-learning-with-python-third-edition) by françois chollet and matthew watson. [practice folder](deep_learning_with_python/).
2. [hands on machine learning with scikit learn and pytorch](https://github.com/ageron/handson-mlp) by aurélien géron. [practice folder](machine_learning_with_scikit_learn_and_pytorch/).
3. [build a large language model from scratch](https://www.manning.com/books/build-a-large-language-model-from-scratch) by sebastian raschka. [practice folder](build_a_large_language_model_from_scratch/).
4. [build a reasoning model from scratch](https://www.manning.com/books/build-a-reasoning-model-from-scratch) by sebastian raschka. [practice folder](build_a_reasoning_model_from_scratch/).
